# Engenharia de Software

**Aluno:** Murilo Mendes Santos  
**Curso:** Ciência da Computação

Este repositório foi criado para a realização de atividades acadêmicas da disciplina de Engenharia de Software, com foco no aprendizado de controle de versões utilizando o GitHub.

## Objetivo do Repositório

O objetivo deste repositório é praticar o fluxo de trabalho com controle de versões, utilizando commits para registrar alterações, branches para desenvolver mudanças separadamente e Pull Requests para revisar e integrar modificações à branch principal.

## Aprendizados

- Criar e organizar um repositório público.
- Registrar alterações por meio de commits descritivos.
- Criar e utilizar branches.
- Abrir Pull Requests e revisar mudanças.
- Incorporar alterações à branch principal utilizando o merge.
